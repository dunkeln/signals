# Signal

Signal turns email-native procurement reality into an operating map: supplier data flow, workflow activation, slowdowns, healthy lanes, blocked handoffs, and evidence-backed value.

It helps FDEs, customer success, product, and operators see where a customer is getting value, where work is stuck, and which source-backed context matters for interpretation. The core unit is not a dashboard metric in isolation; it is a source-backed workflow signal tied to supplier emails, documents, extracted records, owners, and business impact.

Signal is built for mid-market CPG teams running sourcing, QA, R&D, and operations through messy supplier communication. It makes traffic, throughput, activation, risk, and value legible enough that a COO, engineer, FDE, or customer-facing operator can reason from the same evidence.
